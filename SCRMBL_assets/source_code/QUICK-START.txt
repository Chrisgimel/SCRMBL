🔧 TO EDIT YOUR APP:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Option 1: Edit SCRMBL.html directly
    • Open in text editor (VS Code, Notepad++)
    • Find line 72: <script type="text/babel">
    • Make changes to JSX code
    • Save and refresh browser

  Option 2: Edit source and rebuild
    • Edit: scrmbl-browser.jsx
    • Run: bash build-standalone.sh
    • New SCRMBL.html created
